# Maintenance

Read AGENTS.md, ARCHITECTURE.md and HARNESS.md before edits. Preserve user changes, source art, manifest order and regression evidence.

| Change | Owner and regression |
| --- | --- |
| Connection rules or board generation | src/model.ts; zero/one/two-bend and exterior paths, reproducible full witnesses, input-only completion, verify/E2E |
| Score, timer, hint or shuffle | Game; duplicate/terminal/pause/time-boundary/deadlock regressions |
| Touch/keyboard/dialogs | src/main.ts; real click/key/tap checks, focus retention, pause and storage failure |
| Layout | src/style.css; six viewports, route perimeter bounds, frozen maximum mascot animation, screenshots |
| Character art | Preserve art/source; pack-art + manifest + check-assets; every pose on dark/checkerboard and actual HUD sizes |
| Dependencies/build | npm ci, npm run verify, npm run test:e2e, npm audit; keep lockfile generated by npm |

No failed test may be disabled to ship a change. No screenshot baseline is an automatic pixel-diff oracle; review intended differences. docs/qa-failures preserves initial overflow evidence; docs/screenshots contains reviewed references.

The normal app has no test hooks. Test-only fixtures require ?test=1 and are never used as proof of complete gameplay. The full browser playthrough selects actual matching pairs through button clicks. Browser dimensions/touch emulation do not establish physical-device gesture behavior.

Storage key chibilink.v1 is versioned. Preserve existing progress/settings during compatible updates; do not delete user data to repair unrelated issues. Effects and renderer must never assign game outcomes.

Run ./scripts/dev-local.sh on this Mac when PATH still points at Node 16. It selects an adequate current Node or the bundled Codex Node runtime; it does not change system Node. Other machines should install the .nvmrc version and npm ci.
